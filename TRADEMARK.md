# Etude name and logo

The code is AGPL-3.0, but the name **Etude**, the **ε** logo and the etude.study domain belong to João Henrique Costa Araujo and are not covered by the code license.

You can:

- say that your project is based on Etude, forked from Etude, or works with Etude;
- use the name and logo to talk about Etude itself (articles, videos, reviews, tutorials);
- keep using the name in an unmodified copy you run for yourself.

You need written permission (hello@etude.study) to:

- publish a modified version, fork or hosted service under the name Etude or with the ε logo;
- use a name or logo that could be confused with Etude;
- sell anything under the Etude name.

If you fork Etude, give it a different name and logo, and remove the links to Etude Sync and the Etude Market unless you have an agreement to use them.
