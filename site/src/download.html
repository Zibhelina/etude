Installation

Get εtude running.

Etude runs on your own computer and opens in your browser. Install it once, then study from your desk, your phone or anywhere on your network.

v{{VERSION}} what's new in this version →

Download for Mac

One app with everything inside. No terminal, nothing else to install.

Download for Apple Silicon Mac with an Intel chip?
  1. Open the file and drag Etude into Applications.
  2. Open Etude. The first time, macOS asks you to confirm: go to System Settings → Privacy & Security and click Open Anyway.
  3. That's it. It opens with a showcase deck to try, and your collection stays in ~/.etude.

macOS 12 or newer, about 140 MB. Not sure which chip you have? Apple menu → About This Mac: "Apple M…" is Apple Silicon.

Install

Four steps and Etude is running. Update it later with git pull and npm run build.

  1. Install Node 24 or newer

    Etude runs on Node. Node runs its TypeScript directly, so there's no compile step for the server.

$ cd etude
$ npm install
$ npm run build

Turn on AI grading

          
Put a key in ~/.etude/.env and restart. Settings → AI grading has presets for OpenRouter, OpenAI and a local server, and a button that grades a sample answer.

          
OPENROUTER_API_KEY=sk-or-your-key-here

          
SECURITY.md lists exactly what is sent to the provider.

        

        

          
Study on your phone

          
By default the server only listens on your computer. Give it a token to open it on your network, then add it to your home screen.

          
$ npm start -- --host 0.0.0.0 --token YOUR-SECRET

          
Then open this address on the phone and add it to the home screen. Away from home, use a private network such as Tailscale, or a reverse proxy with TLS.

          
http://<your-computer>:4610/?token=YOUR-SECRET

        

        

          
Give it to your agent

          
The repo ships skill/SKILL.md. Drop it into an agent's skills folder and it can build packs, quiz you and find weak cards.
